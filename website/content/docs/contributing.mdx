Samata is developed in the open at
[github.com/samata-oss/samata](https://github.com/samata-oss/samata).

## Repo layout

```text
docker-compose.yml        Dev infra: LiveKit, Postgres, worker (profile)
docker-compose.sip.yml    Adds LiveKit SIP and Redis for local phone calls
deploy/                   Production compose (prebuilt images + Caddy) and .env.example
infra/livekit/            Dev livekit.yaml, sip.yaml
control-plane/            Next.js, Hono under /api, Drizzle, Dockerfile
worker/                   livekit-agents worker, Dockerfile
examples/webhook-server/  Example tool and event server
website/                  This site (landing page and docs)
.github/workflows/        Multi-arch image builds, published to GHCR
```

## Develop

Follow the [Quickstart](/docs/quickstart). Useful scripts, all run from the repo root:

| Command                | What it does                                                   |
| ---------------------- | -------------------------------------------------------------- |
| `pnpm dev`             | Control plane on `localhost:3000`                              |
| `pnpm worker:dev`      | The worker                                                     |
| `pnpm simulate:call`   | Run the webhook lifecycle without any audio                    |
| `pnpm example:webhooks`| The example tool server on `localhost:4000`                    |
| `pnpm db:studio`       | Browse the database                                            |
| `pnpm site:dev`        | This site on `localhost:3100`                                  |
| `pnpm lint`, `pnpm typecheck` | Biome and TypeScript                                    |

To run the worker as a container instead (it doesn't need the rest of the stack to
build):

```bash
docker build -t samata-worker ./worker
docker compose --profile worker up -d worker
```

## Writing docs

These docs live in `website/content/docs` as MDX. Add a page by creating a file
there and listing it in the nearest `meta.json`.
